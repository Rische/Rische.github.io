RESUME

A list of programs and tools I have developed to assist me in designing video games, either for myself or other members of my team.

Some problems require better tools than simple lines of code, with a dedicated and intuitive interface, which is why I have developed these tools throughout my career.

Orbi Universo II - Gaïa, Terrain editor

A terrain editor used during the development of the game Orbi Universo II.
Allows you to import a world map in the form of a vector image file and configure the geography, climate, and natural resources of each region of the world.

Animation editor

Images always have their origin point in the upper left corner, and giving them an arbitrary offset value to re-center the origin is not the best method, especially with the large number of images that make up some animations.

I created this program to add metadata to a list of images, such as an origin point or a number of sub-animations for multiple-angle views.
The metadata is saved in a file and imported into the game engine along with the images to recreate the animation in the game.

Tilemap editor

A program that allows you to edit a two-dimensional grid and assign a value to each cell to form a “tilemap.” Also supports editing multiple lists of arbitrary points on the grid space.
The data is saved in a file and imported into the engine to recreate the gameplay area on the grid.

Dialog editor

A dialogue editor plugin for Unity used during the development of the game Camp.us. Allows you to create multiple-choice dialogues and trigger in-game events.

Custom programming language

A language I developed for modding support for the game Orbi Universo. For more information, visit the page dedicated to the game (French only)
